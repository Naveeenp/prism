# PRISM — PMDC Motor Health Monitor

**PRISM** is a real-time diagnostic and control workstation for PMDC (Permanent Magnet DC) motors, built on an **ESP-32S NodeMCU** microcontroller. It provides live telemetry (speed, current, temperature, vibration), predictive health analytics, automated diagnostics, and a multi-theme browser-based HMI dashboard.

---

## System Architecture

```
Browser Dashboard (HTTP / WebSocket)
        │
        ▼
  FastAPI Server   ◄──────  dashboard/server.py
        │
        ▼
  Backend Engine   ◄──────  backend_engine.py
  (Analytics, Alarms, Physics Simulation)
        │
        ├── Serial Connected ──► ESP-32S NodeMCU (115200 Baud)
        │                         dc_motor_health_monitor/
        │
        └── Simulation Mode  ──► Software Physics Engine
                                  simulation.py
```

## Hardware

| Component | Part | GPIO |
|-----------|------|------|
| Microcontroller | ESP-32S NodeMCU (38-pin) | — |
| Motor Driver | L298N Dual H-Bridge | ENA: 14 · IN1: 27 · IN2: 26 |
| Encoder | HC-89 Optical (4-slot disc) | 18 (IRQ CHANGE) |
| Current/Voltage | INA219 (I²C 0x40) | SDA: 21 · SCL: 22 |
| IMU / Vibration | MPU-6050 (I²C 0x68) | SDA: 21 · SCL: 22 |
| Temperature | DS18B20 1-Wire | 4 (4.7kΩ pull-up) |
| OLED Display | 1.3″ SH1106 128×64 (I²C 0x3C) | SDA: 21 · SCL: 22 |
| Heartbeat LED | ESP32 Onboard Blue | 2 |

## Quick Start

### 1. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the Dashboard

```bash
python run_dashboard.py
```

This opens your browser automatically at `http://localhost:8080`.

> **No ESP32 connected?** The system automatically falls back to a full physics simulation — the dashboard works identically.

### 3. Flash Firmware (Optional)

Install [arduino-cli](https://arduino.github.io/arduino-cli/), then use the helper:

```bash
python esp32_tool.py flash
```

Or open `dc_motor_health_monitor/dc_motor_health_monitor.ino` in Arduino IDE 2.x and upload directly.

## Dashboard Controls

| Control | Action |
|---------|--------|
| **DARK / OLED / LIGHT** | Switch between three themes (persists across sessions) |
| **SCAN → CONNECT** | Connect to ESP32 serial port |
| **ENABLE MOTOR DRIVER** | Arms the L298N H-Bridge output stage |
| **Speed Slider (0–100%)** | Sets PWM duty cycle proportionally |
| **RUN 50% / 75% / 100%** | One-click speed presets |
| **WIND DOWN** | Staged deceleration: 2 seconds per 1% reduction |
| **EMERGENCY STOP** | Instant 0% cut + driver disarm + red flash + 3× alarm beep |
| **Fault Injection** | Simulate overheat, overcurrent, stall, bearing drag, vibration, voltage sag |
| **[ MEASURE Ra ]** | In-situ armature resistance pulse test |
| **[ START COAST-DOWN TEST ]** | Automated bearing condition index measurement |

## Serial Protocol (ESP32 ↔ Backend)

### Commands Sent to ESP32

```
CMD:DRIVER_POWER:<ON|OFF>       # Arm or disarm H-Bridge
CMD:SET_SPEED:<0-255>           # Set PWM duty (0 = stop, 255 = full)
CMD:ESTOP                       # Instant emergency stop
CMD:WIND_DOWN                   # Controlled deceleration (2s per 1%)
CMD:RUN_COAST_TEST              # Automated coast-down test
CMD:MEASURE_RA                  # Armature resistance pulse
CMD:PING                        # Heartbeat check
```

### Telemetry from ESP32 (JSON, 10 Hz)

```json
{
  "mode": "RUN_75",
  "v_bus": 12.04,
  "i_ma": 320.5,
  "rpm": 1820.0,
  "temp_c": 31.4,
  "vib_g": 0.18,
  "ts_ms": 104250,
  "driver_pwr": 1,
  "duty": 191,
  "seq": 1042,
  "pulses": 8368,
  "ina_ok": 1,
  "mpu_ok": 1
}
```

## Alarm Thresholds

| Parameter | Caution | Critical |
|-----------|---------|----------|
| Temperature | ≥ 45°C | ≥ 52°C |
| Armature Current | ≥ 750 mA | ≥ 950 mA |
| Vibration RMS | ≥ 0.80 G | ≥ 1.50 G |
| RPM (stall at duty > 14%) | — | < 25 RPM |
